# TypeScript Lab

Kleiner Lernbereich fuer TypeScript, getrennt von `game-lab`.

## Reihenfolge

1. `src/01-types/cannons.ts`
   - `type`
   - Union Types
   - `interface`
   - `Record`

2. `src/02-functions/weaponActions.ts`
   - Parameter-Typen
   - Rueckgabe-Typen
   - feste Action-Strings

3. `src/03-objects/loadout.ts`
   - Arrays
   - `null`
   - Loadout-Typen

4. `src/playground.ts`
   - freies Ausprobieren

## Ziel

Die Typen sollen sich direkt an Game-Lab orientieren:

- Kanonen-IDs
- Waffen-Daten
- Loadout-Slots
- Klick-Aktionen
